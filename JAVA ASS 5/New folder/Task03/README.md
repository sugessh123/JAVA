Task 3 – Library search screen. `LibraryPanel` contains all the layout; `LibrarySearchScreen` puts it in a window.

- Run the window: `javac *.java` then `java LibrarySearchScreen`, and resize it by hand.
- `java LayoutScreenshots` draws the panel off-screen at three sizes and writes `screenshots/resize_*.png` and `layout_report.txt`. The files provided were produced this way, so they show the real layout managers at work, but they are not screenshots of a window on your desktop: take your own as well.
- Layout choices and resizing analysis are in Assignment_Report.md, Task 3.
